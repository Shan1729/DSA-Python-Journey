# Two Pointers

## Pattern Overview

Two Pointers is a problem-solving pattern where two indices move through a data structure according to specific conditions.

The pointers may move:

- Toward each other
- In the same direction
- At different speeds

## Core Idea

Instead of repeatedly examining the same elements, pointer movement allows us to eliminate unnecessary work and often reduce a brute-force solution to linear time.

## Problems Completed

1. Two Sum II
2. Valid Palindrome

## Key Learning

The most important part of the pattern is not memorizing pointer movements.

It is understanding:

> **What information tells me which pointer should move next?**
